# Vizora.tj

Полноценная платформа цифровых визиток, проверенных специалистов, организаций
и QR-решений для Таджикистана. Основной язык — русский, также предусмотрены
таджикский и английский. Интерфейс проектируется от мобильной версии.

## Возможности

- фирменный экран загрузки и адаптивная навигация Vizora;
- главная страница с преимуществами, примерами, тарифами и FAQ;
- конструктор визитки с живым предпросмотром;
- загрузка фотографии или логотипа;
- три шаблона и пять цветовых тем;
- персональные страницы `/card/:slug`;
- рабочие кнопки звонка, WhatsApp, Telegram, e-mail, сайта и карты;
- генерация и скачивание QR-кода;
- сохранение контакта в формате vCard;
- системная функция «Поделиться» с резервным копированием ссылки;
- демонстрационный личный кабинет с созданием, редактированием и удалением;
- отдельная защищённая админ-панель с реальными показателями;
- открытый каталог проверенных специалистов;
- раздел организаций, структура сотрудников и общий QR;
- заявка организации с тарифами и ручной оплатой;
- профильные услуги: печатные визитки, NFC-карты, QR-бейджи и таблички;
- встроенный справочный помощник и связь с менеджером;
- стартовая квота: первые 50 подтверждённых пользователей бесплатно на 1 год;
- лидогенерация из каждой публичной визитки;
- мини-CRM со статусами, заметками, историей и контролем оплаты;
- корпоративное управление сотрудниками и автоматические фирменные визитки;
- рабочая серверная интеграция Google Wallet для одобренных визиток;
- подготовленный адаптер Apple Wallet до выпуска сертификата PassKit;
- ручная оплата с загрузкой чека, проверкой и кодом активации;
- светлая и тёмная тема;
- локальное демо-хранилище и подготовленная схема Supabase.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, указанный Vite, обычно
`http://localhost:5173/`.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

Собранные файлы появятся в папке `dist`.

## Публикация через GitHub Pages

Workflow `.github/workflows/deploy.yml` автоматически собирает и публикует
сайт после каждого push в ветку `main`.

В настройках репозитория откройте:

1. `Settings`;
2. `Pages`;
3. в разделе `Build and deployment` выберите источник `GitHub Actions`.

После успешного выполнения workflow сайт будет доступен по адресу:

`https://raqibj021.github.io/card-tj2/`

Для прямого открытия внутренних маршрутов добавлен SPA fallback через
`public/404.html`.

## Архитектура данных

Страницы работают не напрямую с `localStorage`, а через интерфейс
`CardRepository` в `src/lib/cardRepository.ts`. Клиент Supabase подготовлен в
`src/lib/supabase.ts`, а начальная безопасная структура базы и RLS-политики
находятся в `supabase/schema.sql`.

Для подключения создайте `.env.local`:

```bash
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_KEY
```

Секретный service-role ключ нельзя добавлять в браузер, `.env` или GitHub.

После предыдущих миграций выполните в Supabase SQL Editor файл
`supabase/migrations/007_admin_console_launch.sql`. Он добавляет сводную
статистику администратора, журнал безопасности, безопасную очистку тестовых
данных и однократный официальный запуск платформы.

Затем выполните `supabase/migrations/008_transactional_email.sql` и
`supabase/migrations/010_email_delivery_completion.sql`. Серверный обработчик
очереди, бесплатный Gmail-шлюз и автоматический запуск каждые 10 минут описаны
в `docs/email-setup.md`.

## Финальный запуск на домене

Единый порядок подключения Cloudflare Pages, домена, redirect URL, служебной
почты и Google Wallet находится в `docs/production-launch.md`. Адрес сайта
задаётся через `VITE_PUBLIC_SITE_URL`, поэтому QR-коды, ссылки и авторизация не
зависят от конкретного хостинга.

## Текущие ограничения

- Apple Wallet ожидает официальный сертификат PassKit;
- Google Wallet публикуется после одобрения профиля эмитента Google;
- ссылка на созданную локально визитку не переносит данные на другое устройство;
- серверная статистика просмотров пока отсутствует.

## Маршруты

- `/` — главная;
- `/directory` — каталог специалистов;
- `/organizations` — организациям;
- `/organization/apply` — заявка организации;
- `/services` — визитки и QR-услуги;
- `/create` — конструктор;
- `/dashboard` — личный кабинет;
- `/dashboard/leads` — лиды и мини-CRM;
- `/admin` — отдельная защищённая админ-панель (ссылка не показывается на публичном сайте);
- `/admin/payments` — проверка оплат;
- `/payment` — ручная оплата тарифа;
- `/support` — связь с менеджером;
- `/card/:slug` — публичная визитка.
